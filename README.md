# SpendWise 💰

SpendWise is a responsive and interactive web-based budgeting dashboard designed to help users track monthly expenses, monitor remaining funds, and maintain healthy financial habits.
 live link https://budgettracker7yyy.netlify.app/
## 🚀 Features
* **Interactive Expense Logging:** Add custom expense descriptions and amounts through a clean form interface.
* **Dynamic Calculations:** Automatically computes total expenditures and remaining budget in real-time.
* **Smart Budget Warnings:** Uses conditional logic to evaluate spending and alert users if they approach or exceed their monthly budget limits.
* **Persistent DOM Updates:** Dynamically renders expense records directly onto the webpage without requiring page reloads or console checks.

## 🛠️ Technologies Used
* **HTML5:** Semantic page layout and structure.
* **CSS3:** Custom styling, layout design, and dynamic alert color-coding.
* **JavaScript (ES6+):** Array management, loop processing, DOM manipulation, and event handling.
